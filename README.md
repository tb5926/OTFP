This is a project for DCS World for the F/A-18C using JS, HTML and node.js.  
The program created from this project is called 'fa-18c-otfp' and is a executable ready for install in widows ***LINK BELOW***.
Follow the readme file to walk through the setup which places a hook file and esport script.
After connecting to a DCS server or single player game one has the ability to import game data via the SYNC DCS button to provide:
  - Weapons, weight and balance, trim settings, rotate speeds, fuel quantity at start of mission.
  - Get communications presets in the aircraft and Save a PNG to your saved games / kneeboard folder.
The user has the ability to:
  - Allow a user to create a route via a leaflet map interface what shows the ingame units realtime for fast planning.
      - Push the waypoints to the aircraft with the click of a button 'PUNCH'
  - Gather live brief data like ingame weather, targets near selected waypoints and supporting agencies (filter out un-needed via task).
  - Kneeboard generator with threat analysis based on route altitude and filtered type LORAD, AAA, ARMOR (SHIPS TO COME)
      - Save kneeboard as PNG and sends it to your saved games kneeboard folder.
   
This is also fully integrated with Openkneeboard tohave a live moving map.
   
  The goal is to give a user a 5 minute or less planning tool to get departure data, Theater Info, and input route waypoints in less than 5 minutes.
