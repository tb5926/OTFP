FIRST TIME SETUP:
Settings > Map Saved Games\DCS folder > Press Install / Update Scripts

OPENKNEEBOARD USE:
Settings > Tabs > + Add a Tab > Web Dashboard > enter link below.

http://localhost:3000?mode=kneeboard

SCRIPT REMOVAL:
Settings > Remove Scripts from DCS

DEBUGGING:
debugAll.html can be accessed by CMD npm start and open in browser http://localhost:3000/debug.html
debug.html, weather.html and dcs-endpoint-match can be opened without starting a server.  just join game and click html to open.
